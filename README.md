### A modular approach to railway safety screening.

**Trinetra–BareMetal** explores a detachable sensor core designed for use across a mobile robot, a handheld device, and a fixed monitoring node.

The concept brings together complementary sensing, evidence corroboration, and human review to support more informed screening decisions.

| Form factor | Proposed purpose |
| :--- | :--- |
| **Mobile robot** | Bring the sensor core to different locations for screening. |
| **Handheld device** | Support focused checks by an operator. |
| **Fixed node** | Support monitoring at a designated location. |

**The proposed workflow**

Screen → Corroborate → Decision support → Human review

The project is presented through a **concept website, simulation, and explainer video**, helping communicate both the system architecture and the intended user experience.

*An evolving student engineering concept; simulation illustrates intended behavior rather than establishing real-world detection performance.*
